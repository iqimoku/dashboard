Dashboard posiada wbudowany moduł pobierania kursów giełdowych oraz status połączenia sieciowego (LIVE / OFFLINE).

Planowane usprawnienia (Roadmap):
Wdrożenie nieoficjalnego Skanera API TradingView za pośrednictwem darmowego CORS proxy (corsproxy.io), aby automatycznie i na żywo zasilać dashboard wartościami średnich kroczących (SMA50, SMA150, SMA200) oraz wskaźnikiem RSI, bez konieczności ręcznego aktualizowania bazy snapshotów.

Integracja ze wskaźnikiem Mansfield Relative Strength (RS): Pełna implementacja oryginalnego podejścia Weinsteina mierzącego siłę relatywną spółki względem indeksu bazowego (np. WIG lub S&P500).

Wizualizacja formacji VCP (Volatility Contraction Pattern): Dodanie wskaźników śledzących zwężanie się zmienności wokół punktów zwrotnych (Pivot Points).
